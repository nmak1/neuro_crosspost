# AutoPoster — Система кросс-постинга в VK и Telegram

Веб-приложение — админ-панель для управления системой автоматической генерации и кросс-постинга контента в ВКонтакте и Telegram с помощью LLM.

## 🚀 Возможности

- **Обзор** — дашборд со статистикой, статусом API и последними событиями
- **Темы** — управление базой тем для генерации контента (фильтрация, поиск)
- **Публикации** — история опубликованных постов с превью VK/TG контента
- **Логи** — журнал системных событий с фильтрами по уровню и компоненту
- **Архитектура** — полная документация структуры проекта и workflow
- **Настройки** — конфигурация API-ключей, расписания, LLM и retry-стратегии

## 🛠 Технологический стек

- **React 18** + **TypeScript**
- **Vite** — сборщик
- **Tailwind CSS 4** — стилизация
- **Framer Motion** — анимации
- **Lucide React** — иконки
- **Recharts** — графики (опционально)

## 📋 Бэкенд (Python)

Веб-панель является фронтендом для системы автопостинга. Бэкенд реализован на Python 3.10+ и включает:

- `core/llm_client.py` — генерация контента через YandexGPT / GigaChat / OpenAI
- `core/vk_publisher.py` — публикация в ВКонтакте (wall.post)
- `core/tg_publisher.py` — публикация в Telegram (sendMessage)
- `data/topics.json` — база тем
- `data/state.json` — состояние (использованные темы)
- `prompts/` — шаблоны промптов для VK и TG

## 🔒 Безопасность
